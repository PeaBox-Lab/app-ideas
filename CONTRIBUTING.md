# Contributing

Thank you for improving PeaBox Builder Ideas.

## Good contributions
- Add evidence from a primary or reputable source.
- Tighten the problem statement or target user.
- Add testable user stories and Given/When/Then acceptance criteria.
- Clarify MVP boundaries, security risks, or platform limitations.
- Link a working open-source implementation.

## Add a new idea
1. Copy `docs/IDEA_TEMPLATE.md` into the appropriate `ideas/` tier.
2. Use a lowercase kebab-case filename.
3. Keep the MVP narrow enough for the stated effort.
4. Add evidence links as plain URLs in the references section.
5. Add the idea to the README table.
6. Run a Markdown link checker before opening a pull request.

## Pull requests
Explain the user value, scope change, and how you verified the links and acceptance criteria. Do not include secrets, personal data, copied proprietary requirements, or generated claims presented as evidence.
