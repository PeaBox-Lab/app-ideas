# PeaBox Builder Ideas v0.2.0 — 100 Ideas

## Highlights

This release doubles the catalogue from 50 to 100 build-ready software ideas and introduces category-based navigation.

## Added

- 50 new idea pages numbered 51–100.
- New collections for developer tools, AI engineering and agents, APIs, DevOps and cloud, self-hosting, security and privacy, data engineering, documents and OCR, productivity, and desktop software.
- `CATALOG.md` containing all ideas by difficulty.
- `docs/CATEGORIES.md` containing all ideas by product category.
- Category metadata in `ideas.json`.
- Evidence-status guidance for unvalidated product hypotheses.

## Improved

- README redesigned around the 100-idea collection.
- New idea pages include six MVP user stories with acceptance criteria.
- Each new page includes architecture guidance, non-goals, delivery plan, success measures, guardrails, business path, and Definition of Done.

## Compatibility

The existing 50 pages and their filenames remain intact. Existing links continue to work.

## Upgrade

Replace the v0.1.0 repository contents with this release, preserving any local customization. If consuming the JSON catalogue, note the new optional `category` property.
