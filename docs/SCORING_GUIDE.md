# Idea scoring guide

Score each dimension from 1 (weak) to 5 (strong).

| Dimension | Question |
|---|---|
| Pain | Is the problem frequent, costly, risky, or frustrating? |
| Reach | Are there enough identifiable users with this problem? |
| Differentiation | Is the focused approach meaningfully better than existing options? |
| Buildability | Can one maintainer deliver a credible MVP with the proposed stack? |
| Demonstrability | Can the value be shown with a sample or short demo? |
| Open-source fit | Can users self-host or extend it without a proprietary dependency? |
| Sustainability | Is there an ethical paid path such as hosting, support, or connectors? |

Prioritize ideas scoring at least 24/35, with no score below 3 for Pain, Buildability, or Demonstrability.
